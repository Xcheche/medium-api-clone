## 🔐 Authentication Stack Overview

### django-allauth

Provides the core authentication logic for the application.
It handles user registration, login, logout, email verification, password reset, and optional social authentication.
All authentication rules and workflows are managed here.

---

### dj-rest-auth

Exposes django-allauth’s functionality as RESTful API endpoints.
It allows frontend clients (such as web or mobile apps) to interact with authentication features using JSON requests instead of HTML forms.
It acts as a bridge between django-allauth and Django REST Framework.

---

### djangorestframework-simplejwt

Implements JSON Web Token (JWT)–based authentication.
It generates access and refresh tokens after successful login, enabling secure, stateless authentication for API requests.
